Готовое — отмечено ✅, за тобой — ⬜.

Это про канал `appstore` (магазин Apple). Отдельно от него живёт канал `ios` —
неподписанный `.ipa` для sideload, он остаётся как был и в App Store не идёт.

`NSLocalNetworkUsageDescription`
✅ Строки доступа к камере и фотоплёнке, семь локализаций, экспортное
соответствие (`ITSAppUsesNonExemptEncryption=false`), `UIFileSharingEnabled`

(ровно на этом Togetherly получил отказ по 2.1)
✅ Минимум iOS 15.5 (требование ML Kit). **Только iPhone**
(`TARGETED_DEVICE_FAMILY = 1`): на планшете вёрстку никто не проверял, а

там Togetherly ловил отказы. На iPad приложение ставится в режиме
совместимости. Вернуть поддержку — когда будет на чём проверить
✅ Job `appstore` в `.github/workflows/release.yml`: подпись, сборка, проверка
манифеста, заливка в TestFlight

✅ **Share Extension сделан**: таргет `ShareExtension` (`ios/ShareExtension/`),
общий контейнер `group.com.fern.flashcards`, приём текста и ссылок. Разбирает

открывает через «Файлы».

✅ **App Group `group.com.fern.flashcards`** заведена, capability включена и
привязана к обоим App ID. Через App Store Connect API группы не создаются
(`/v1/appGroups` отвечает 404) — только портал; API умеет включить саму
capability, но без привязки группы профиль выпускается с пустым списком, и
сборка падает на «doesn't support the group… App Group».

✅ **Сборка 1.21.0 (34) залита в TestFlight** (2026-08-07), статус VALID.

⬜ **На живом устройстве не проверялось ничего.** Mac и iPhone в хозяйстве нет,

напоминания.

## 2. Секреты GitHub

Без них job `appstore` пропускается — тег всё равно соберёт остальные каналы.

| Секрет | Где взять |
|---|---|
| `APPSTORE_ISSUER_ID` | App Store Connect → Users and Access → Integrations → App Store Connect API, значение Issuer ID |
| `APPSTORE_KEY_ID` | там же, Key ID созданного ключа |
| `APPSTORE_PRIVATE_KEY` | содержимое скачанного `AuthKey_XXXX.p8` целиком, вместе со строками BEGIN/END. Файл дают скачать один раз |
| `APPSTORE_CERT_KEY` | `openssl genrsa 2048` — ключ придумываешь сам и хранишь навсегда |
| `APPSTORE_APP_ID` | числовой id приложения в App Store Connect (App Information → General → Apple ID). Не обязателен: без него номер сборки берётся из pubspec |

Все пять секретов заведены 2026-08-07; ключ API — «Codemagic.» (`XU8YHQFQAX`,
роль Администратор), копия `.p8` и ключ сертификата лежат в `~/keys`.

**Заливка без выпуска остальных каналов:** Actions → Release → Run workflow →
флажок `only_appstore`. Тег `vX.Y.Z` по-прежнему раскладывает Fern сразу по
всем пяти каналам.

⬜ Ключ App Store Connect API создать с ролью **Admin** или **App Manager** —
роль Developer отдаёт 401 на заливке.

⬜ `APPSTORE_CERT_KEY` завести ОДИН раз и не менять. С новым ключом
`fetch-signing-files --create` каждый прогон выпускает новый сертификат
распространения, а их лимит у Apple маленький: Togetherly выел его за
одиннадцать сборок, и дальше пришлось руками отзывать мусор в портале.

⬜ **Встроенная покупка** `fern_pro`: тип **Non-Consumable**, цена **9,99 $**,
названия и описания на русском и английском. Обязателен **скриншот экрана

Цена на iOS вдвое выше, чем в Play и RuStore (4,99 $), намеренно: аудитория
платит охотнее, а соседи по категории стоят дороже (AnkiMobile около 25 $).
Плата за это — человек, купивший Pro на Android, на iPhone платит заново:
покупка между магазинами не переносится, а ключ от бота на iOS запрещён
правилом 3.1.1.

⬜ **App Privacy → Data Not Collected.** Ответ должен совпадать с

⬜ **Возрастной рейтинг.** Ставим 4+. В анкете есть вопрос про неограниченный
доступ в интернет — у Fern его нет: браузера внутри нет, статья по ссылке
разбирается в текст, видео открывается официальным плеером YouTube. Если ревью
не согласится, спорить не о чем — поднять до 12+ и переподать.

## 5. Порядок первого выпуска

1. Завести секреты (раздел 2) и приложение в консоли (разделы 3–4).
2. Поднять версию в `app/pubspec.yaml`, описать её в `CHANGELOG.md`,
   закоммитить, запушить.
3. `git tag v1.22.0 && git push origin v1.22.0`.
4. Дождаться job `appstore`: он подпишет, соберёт и зальёт сборку в TestFlight.
   Номер сборки берётся из TestFlight и увеличивается на единицу, поэтому
   versionCode Android с ним расходится — так и должно быть.
5. Проверить сборку в TestFlight на живом устройстве.
6. В App Store Connect привязать сборку к версии, заполнить «Что нового»,
   приложить встроенную покупку **к первой подаче** и отправить на ревью.

Дальше теги работают сами: каждый выпуск кладёт новую сборку в TestFlight, а
отправка на ревью остаётся ручной — она необратима.

## 6. Что ловит ревью

Собрано по отказам Togetherly, чтобы не проходить их второй раз.

- **3.1.1, оплата мимо Apple.** В сборке для App Store не должно появиться ни
  ключа из бота, ни ссылок на Boosty, DonationAlerts, lava.top, ни слов про
  покупку на сайте. Сейчас всё это закрыто `kAppStoreBuild`; при добавлении
  новых кнопок оплаты проверять ветку.
- **2.1, «кнопка не работает».** Ревью идёт на iPad. Всё, что открывает
  системный лист, обязано передавать `sharePositionOrigin`
  (`lib/utils/share_origin.dart`).
- **ITMS-90338, приватные API.** Автопроверка бинарника читает строки. У Fern
  нет ни `flutter_inappwebview`, ни `flutter_webrtc` — тех, на которых
  спотыкался Togetherly, — но при добавлении новых пакетов с нативным кодом
  стоит прогнать `strings` по сборке.
- **ITMS-91053, манифест приватности.** Job падает сам, если
  `PrivacyInfo.xcprivacy` не попал в бандл.
- **2.1(b), «не нашли покупку».** В Notes для ревьюера писать маршрут словами:
  Библиотека → «Добавить книгу» → после первой книги открывается лист «Fern
  Pro». Первый источник бесплатен, поэтому лист виден не сразу — без объяснения
  ревьюер до покупки не дойдёт.
- **5.2.3, чужой контент.** Разбор видео берёт субтитры и звук ролика, ссылку
  на который дал сам человек. Если спросят, отвечать так: приложение не
  скачивает и не хранит видео, показывает его официальным плеером, а работает с
  субтитрами конкретной ссылки.

### Заметки для ревьюера (App Review Information → Notes)

```
Аккаунта в приложении нет, вход не требуется — всё работает офлайн на устройстве.

Где встроенная покупка: вкладка «Библиотека» → «Добавить книгу» (или «Разобрать
видео»). Первый источник разбирается бесплатно, после него открывается лист
«Fern Pro» с покупкой fern_pro. Тот же лист доступен всегда: Настройки → раздел
«Fern Pro».

Что открывает покупка: работу со своими материалами — книги, видео, статьи,
распознавание текста с фотографии, перенос колод из Anki и таблиц. Карточки,
режимы занятий, статистика, напоминания и резервные копии бесплатны без
ограничений.

Приложение не собирает данные и не отслеживает пользователей. В сеть выходит
только по действию человека: перевод слова, словарная справка, субтитры видео,
статья по ссылке.
```

## 7. Что дальше

- Скриншоты снимаются в симуляторе на macOS. Своей машины с ней нет, поэтому
  либо чужой Mac, либо отдельный job на раннере GitHub Actions.
- Перевод карточки на остальные пять языков интерфейса — после того, как
  приложение выйдет и станет понятно, откуда идут установки.
- Расширение «Поделиться» собирается вместе с приложением, но на устройстве не
  проверялось. Смотреть в TestFlight: Safari → «Поделиться» → Fern, лист
  открывается с текстом или ссылкой. Первая сборка после его появления — самое
  вероятное место, где всплывёт ошибка компоновки подов
  (`use_modular_headers!` в Podfile нужен именно расширению).
