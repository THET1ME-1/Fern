# Карточка App Store — тексты

Копировать в App Store Connect как есть. Описание лежит отдельными файлами
(`description-ru.txt`, `description-en.txt`): при копировании из markdown текст
склеивается, и на этом Fern уже споткнулся один раз в Google Play.

Локализации карточки — русская и английская. Английская показывается везде,
где нет своей: интерфейс приложения знает семь языков, но карточку на семи
языках потом придётся семь раз править.

Apple не разрешает называть в описании и на скриншотах другие платформы и
магазины. Поэтому в текстах для App Store нет ни Android, ни Google, ни
«Material You» — они остались в описании для Play.

## Русская локализация

**Название** (до 30 символов)

```
Fern — карточки для языков
```

**Подзаголовок** (до 30 символов)

```
Слова из книг, видео и фото
```

**Ключевые слова** (до 100 символов, через запятую, без пробелов)

```
карточки,слова,словарь,английский,интервальные,повторения,память,чтение,epub,перевод,язык
```

**Промо-текст** (до 170 символов, меняется без обновления сборки)

```
Учите слова из своей книги, своего видео, своего снимка страницы. Планировщик FSRS вернёт слово ровно тогда, когда память начнёт его отпускать.
```

**Описание** — `docs/appstore/description-ru.txt`

## Картинки для встроенной покупки

| Файл | Куда |
|---|---|
| `promo-A.png`, `promo-B.png`, `promo-C.png` | Изображение покупки, 1024×1024. Три направления, в консоль идёт одно |
| `review-shot-6.9.png` | Снимок экрана для проверки, 1290×2796 (iPhone 6,9″) |
| `review-shot-5.5.png` | Он же в 1242×2208 (iPhone 5,5″), запасной размер |

Промо собирается скриптом `promo-build.py` (в нём же лежат три композиции):
цвета и шрифты берутся из приложения, поэтому правка сводится к правке кода, а
не к ретуши картинки. Рендер — headless Chromium, размер холста 1024×1024.

Снимок для проверки рисуется настоящим `ProSheet` — `flutter test
tool/pro_shot_test.dart --dart-define=STORE=appstore` кладёт файлы в
`app/dist/`. Две ловушки консоли, обе стоили по загрузке:

- **Размер только «устройственный».** Произвольная высота (например,
  1290×2400) отбивается ошибкой «неверные размеры одного или нескольких
  снимков экрана». Работают 1290×2796 и 1242×2208.
- **Альфа-канал не принимается.** `toImage` отдаёт RGBA, поэтому после
  генерации канал снимается:
  `magick файл.png -background black -alpha remove -alpha off -strip файл.png`. Те же виджеты, шрифты и цвета, что увидит человек; цены на нём
нет, потому что вне устройства магазин её не отдаёт. **Как только появится
сборка в TestFlight, снимок лучше заменить настоящим** — с ценой и системным
окном оплаты.

## «Что нового» для версии

Берётся разделом из `CHANGELOG.md` — тем же, что уходит в GitHub Release и в
Play. Лимит Apple — 4000 символов, обрезать не приходится.

## Скриншоты

Обязательны два набора: iPhone 6,9″ (1290×2796) и iPad 13″ (2064×2752).
Снимков — от трёх до десяти в каждом; Apple берёт первые три в поиск, поэтому
первыми ставить главный экран, занятие и читалку с тапом по слову.

Скриншоты для Play (`docs/play/screens-ru`) не подойдут: другое соотношение
сторон и на них видна навигация Android. Снимаются в симуляторе на macOS —
своей машины с ней нет, поэтому это первый пункт, который упирается в чужой
компьютер или в раннер GitHub Actions.
